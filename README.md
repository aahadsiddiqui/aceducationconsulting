# AC Education Consulting

Independent education consulting for **Canadian citizens, permanent residents, and refugees** pursuing master’s and graduate-level programs at community colleges and universities—plus guidance on **OSAP / provincial student aid** and career support after graduation.

We are **not affiliated** with any college or university. We do **not** provide overseas recruitment or visa/study-permit assistance.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
